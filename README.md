### 🧱 A evolução de um projeto: Order Management
O mesmo sistema de pedidos, reescrito em etapas para mostrar o aprendizado:

| Etapa | O que mudou | Repositório |
|---|---|---|
| 1. Java puro | POO a partir de um diagrama UML: composição, encapsulamento e enums | [order-management-system](https://github.com/JkbSousa/order-management-system) |
| 2. Spring Boot + H2 | API REST com JPA/Hibernate, relacionamentos entre entidades, cascade e camadas | [order-management-spring](https://github.com/JkbSousa/order-management-spring) |
| 3. Spring Boot + PostgreSQL | Fluxo completo de e-commerce, validação, Docker e documentação Swagger | [order-management-api](https://github.com/JkbSousa/order-management-api) |

```text
Controller → Service → Repository → Database
```
